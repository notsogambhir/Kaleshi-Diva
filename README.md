# Kaleshi Diva (Sunflower Run)

A 3D endless runner game built with React, Three.js, and Vite — playable in the browser and packaged as an Android app via [Capacitor](https://capacitorjs.com/).

Run, dodge obstacles, collect sunflowers, grab power-ups (magnet, shield, speed dash), and stay ahead of the pursuer across procedurally generated Garden, Lake, and Jungle biomes.

## Play in the browser

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

No API key is required — the game is fully offline.

## Build the Android app

**Prerequisites:**

- Node.js
- JDK 17+ (`JAVA_HOME` set)
- Android SDK (via Android Studio), with `ANDROID_HOME` set or `android/local.properties` pointing to it

**Build a debug APK (for sideloading on your phone):**

```bash
npm run android:apk
```

The APK lands at `android/app/build/outputs/apk/debug/app-debug.apk`.

**Or work on it in Android Studio:**

```bash
npm run android        # builds web assets, syncs, and opens Android Studio
```

**To install on your phone:** copy the APK to the device (or download it via drive/USB), open it, and allow "Install unknown apps" when prompted. Debug APKs don't need Play Store signing.

## How the Android packaging works

- `vite build` produces static files in `dist/` (with relative asset paths via `base: './'`).
- `npx cap sync android` copies them into the native Android project in `android/`.
- The app runs in an offline system WebView; swipe controls and localStorage high scores work as on the web.
- The Android app is locked to portrait mode and keeps the screen awake during gameplay (see `android/app/src/main/AndroidManifest.xml` and `MainActivity.java`).

## App icon

The icon and splash screens are generated from source images in `assets/` using `@capacitor/assets`. The placeholder sunflower art itself is generated by `scripts/generate-icon.ps1` (PowerShell + System.Drawing). To swap in custom art:

1. Replace `assets/icon.png`, `assets/icon-foreground.png`, `assets/icon-background.png`, and `assets/splash.png` / `assets/splash-dark.png` (1024×1024 icons, 2732×2732 splash).
2. Run `npx capacitor-assets generate --android`.

## Releasing to Google Play (later)

Debug APKs are for personal use. For the Play Store you'll need a release keystore and `gradlew bundleRelease` in `android/` — see the [Capacitor publishing guide](https://capacitorjs.com/docs/android/deploying-to-google-play).
